# 微信读书自动阅读

一个轻量的油猴脚本，让微信读书网页版自动滚动。主要用于 PDF 扫描版这类连续长流内容——不需要翻页，一路滚到底。

## 为什么自己写

原本用的是 [DoooReyn/WxReader](https://github.com/DoooReyn/WxReader)（Python + PySide6 + cefpython3 的桌面客户端），它有两个绕不过去的问题：

1. **内核死了**。它依赖的 `cefpython3` 官方最后一个版本 v66.1 发布于 2021-02-16，对应 Chromium 66——一个 2018 年的浏览器内核。作者自己在 README 里写着"开发环境最高支持到 Python 3.7"。拿这个内核开现在的网页，白屏和缺组件报错几乎必然。
2. **选择器失效**。实机验证，它翻页依赖的 `.readerFooter_button`、`.readerFooter`、`.readerTopBar_button` 类名在当前的微信读书页面上**匹配数全部为 0**。官方改版之后，这套逻辑已经彻底找不到目标。

第 2 点是硬伤：改不了，只能跟着官方走。

## 特点

- **默认仅滚动不翻页**。PDF 扫描版是连续长流，滚到底就是读完，不会去按任何键（避免在扫描版上触发意外跳转）。
- **滚动容器实测探测**。不硬编码 class，而是真的滚动 1px 验证是否生效。微信读书的正文是 window 级滚动，可以直接对上。
- **后台防节流**。浏览器会把后台标签页的 `setInterval` 节流到约每分钟一次，挂机就白挂了。定时器放进 Web Worker 绕过这个限制；若站点 CSP 拦截则自动退回页面内定时器，并在面板上如实标注。
- **进度与剩余时长**。按当前速度推算还要多久滚完。
- **自检诊断**。一键导出滚动容器、可滚动候选、页面环境等信息，页面改版后据此快速定位问题。
- **保留翻页能力**。读普通电子书时可取消"仅滚动"勾选，脚本内置 PageDown / 方向键 / 空格 / 点击按钮四种方式，可自动轮转。

## 安装

1. 浏览器装 [Tampermonkey](https://www.tampermonkey.net/)（篡改猴）
2. 打开 `weread-autoread.user.js`，Tampermonkey 会提示安装
3. 访问 [weread.qq.com](https://weread.qq.com) 并登录，打开任意一本书
4. 右下角出现控制面板，点开关或按 `Ctrl+Enter` 启动

## 使用须知

- **Edge 必须关闭标签页休眠**：`edge://settings/system` → 关闭"将非活动标签页置于睡眠状态"。否则后台不计时。
- 建议让标签页保持在前台，面板上的"页面可见"和"定时器"两栏会如实显示当前状态。
- 全部配置自动保存在本地，下次打开沿用。

## 面板说明

| 字段 | 含义 |
|---|---|
| 状态 | 当前是否在自动滚动 |
| 滚动容器 | 实际在滚动的元素 |
| 进度 | 阅读进度 + 按当前速度估算的剩余时长 |
| 翻页方式 | 当前使用的翻页策略（仅滚动模式下不生效） |
| 定时器 | 定时器来源。显示 Worker 表示后台可正常工作 |
| 本次时长 | 本次启动以来累计时间 |

## 快捷键

| 按键 | 作用 |
|---|---|
| `Ctrl+Enter` | 开启 / 关闭自动阅读 |

## 诊断报告

页面改版导致脚本失效时，点面板上的「自检诊断」，脚本会输出一份报告并自动复制到剪贴板，包含：

- 所有可滚动元素及其实测可滚动性
- 当前选中的滚动容器
- 页面上的 `reader*` 类名清单
- 视口顶部文本、页面可见性、定时器来源

在仅滚动模式下，诊断会跳过翻页策略实测（那一步会真的翻页）。

## 已知限制

- 自动阅读用于刷阅读时长，属于微信读书用户协议的灰色地带。**仅供个人使用，请勿公开发布或商用。**
- 脚本依赖微信读书的页面结构。官方改版后可能需要调整，届时用诊断报告定位。
- 未在登录态下做过全量自动化测试，实际效果请以你的账号环境为准。
